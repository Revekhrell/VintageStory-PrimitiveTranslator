# PrimitiveTranslator

Утилита для сравнения и перевода файлов локализации модов VintageStory. Собирает словари из zip-архивов модов, сравнивает их с уже имеющимися переводами, подсвечивает непереведённые и устаревшие ключи, позволяет редактировать словари вручную и автоматически переводить их через GTranslate.

---

## Возможности

### Чтение модов
- Сканирование папки с zip-архивами модов.
- Извлечение `modinfo.json` и словарей локализации из
  `assets/modid/lang/<lang>.json`.
- Объединение данных из нескольких архивов: если один мод дополняет словари другого, ключи и значения сливаются в одну модель.
- Исключение мода-переводчика из общего списка (по его `UID` из `modinfo.json`).

### Сравнение и подсветка
- Сравнение оригинального и переведённого значений по времени регистрации (`Timestamp`).
- Подсветка **новых** ключей (зелёный) – перевода ещё нет.
- Подсветка **модифицированных** ключей (оранжевый) – оригинал новее перевода.
- Для модифицированных ключей в редакторе показывается пара
  «оригинал | перевод», чтобы было видно, что изменилось. Разделитель состоит из "U+00A0|U+00A0", если вы, например, используете нейросети для перевода, укажите это.

### Редактор словарей
- Полноценный текстовый редактор на базе AvalonEdit с подсветкой JSON.
- Динамическая подсветка отдельных ключей по мере редактирования.
- Отслеживание несохранённых изменений (флаг `IsModified` и звёздочка в заголовке вкладки).
- Сохранение в базу данных SQLite через EF Core.

### Редактор `modinfo.json`
- Отдельная вкладка для редактирования информации о моде-переводчике.
- Собственный JSON-конвертер для чтения/записи только нужных полей (`modid`, `name`, `version`, `description`).

### Автоматический перевод
- Перевод непереведённых ключей через GTranslate (`AggregateTranslator`).
- Таймаут на каждый запрос, чтобы приложение не зависало при проблемах с сетью.
- Прогресс-бар выполнения.

### Экспорт мода-переводчика
- Сборка zip-архива с `modinfo.json`, `modicon.png` и словарями по указанным языкам.
- Имя архива формируется как `modid[_version].zip`.

### Интерфейс
- Двухпанельное окно: список модов слева, редактор вкладок справа.
- **Мультивыделение в списке модов** – можно выбрать несколько модов одновременно (Ctrl/Shift).
- **Кнопка удаления** – удаляет выбранные моды из списка и базы данных.
- Dragablz-вкладки с горизонтальной прокруткой колёсиком мыши.
- Закрытие вкладки средней кнопкой мыши с предложением сохранить изменения.
- Тёмная тема оформления.

### Сохранение состояния
- Список открытых вкладок и выбранная вкладка восстанавливаются при запуске.
- Состояние окна (размер, положение, `WindowState`) сохраняется в базе.
- Ширина левой панели, язык перевода, папки модов и экспорта, языки экспорта – всё хранится в таблице `Parameters`.
- Выбранные языки модов сохраняются между сессиями.

### Защита от конфликтов
- Блокировка запуска второго экземпляра приложения из одной директории (файл-блокировка `Locker`).
- Контроль параллелизма через `RowVersion` (с `ValueComparer` для `byte[]`).
- Отдельный флаг `IsFreeContext` для предотвращения одновременного доступа к контексту данных.

## Технологии

- **.NET 10** / **WPF**
- **Entity Framework Core** + **SQLite**
- **Dorssel.EntityFrameworkCore.Sqlite.Timestamp** – поддержка `RowVersion` для SQLite
- **AvalonEdit** – текстовый редактор с подсветкой синтаксиса
- **Dragablz** – перетаскиваемые вкладки
- **Prism** (`BindableBase`, `DelegateCommand`)
- **Newtonsoft.Json** – сериализация/десериализация
- **GTranslate** – автоматический перевод
- **Cybrex.Core** – вспомогательные утилиты (коллекции, блокировки, исключения)

## Схема базы данных

| Таблица | Назначение |
|---|---|
| `Parameters` | Пары ключ-значение для сохранения состояния приложения |
| `Languages` | Справочник языков (уникальное имя) |
| `Mods` | Моды с метаданными и ссылкой на язык оригинала |
| `Keys` | Ключи локализации (уникальны в рамках мода) |
| `Values` | Значения ключей по языкам (уникальны в рамках ключа и языка) |
| `ModLanguagesReferences` | Связь many-to-many между модами и языками |

## Использование

1. Запустить приложение.
2. Указать **папку модов** и **папку экспорта**.
3. Указать **язык перевода** (например, `ru`).
4. Нажать кнопку **перезагрузки модов** – приложение просканирует архивы и заполнит базу данных (при указании папки делает атоматически).
5. Выбрать для мода в списке язык оригинала и двойным щелчком открыть словарь для перевода.
6. Перевести нужные ключи вручную или нажать кнопку **автоматического перевода**.
7. Сохранить (`Ctrl+S` – текущая вкладка, `Ctrl+Shift+S` – все вкладки).
8. При необходимости отредактировать `modinfo.json` через одноимённую кнопку.
9. Нажать кнопку **экспорта** – соберётся zip-архив мода-переводчика.

### Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl+S` | Сохранить текущую вкладку |
| `Ctrl+Shift+S` | Сохранить все вкладки |
| Средняя кнопка мыши по вкладке | Закрыть вкладку |

## Особенности реализации

- **Долгоживущий контекст с короткими сессиями.** `DataContext` создаётся перед операцией и освобождается после. Флаг `IsFreeContext` защищает от повторного входа.
- **`RowVersion` через `Dorssel.EntityFrameworkCore.Sqlite.Timestamp`.** позволяет контролировать параллелизм в SQLite, где нет встроенного  `rowversion`.
- **Кастомный `DocumentColorizingTransformer`** для динамической подсветки ключей – не трогает общий `SyntaxHighlighting` и работает по позициям.
- **`DeferredEventHandler`** – debounce для события изменения текста (1000 мс), чтобы не пересчитывать хеш на каждое нажатие.
- **`RefreshTabsOrder`** – синхронизация порядка `Tabs` с визуальным порядком вкладок через `GetOrderedHeaders()` (учитывает ручное перетаскивание).
- **Relationship fixup** используется для автоматической синхронизации навигационных свойств при добавлении сущностей.
